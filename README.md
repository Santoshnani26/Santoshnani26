## 🚀 Featured projects

### FinTrack Pro: AI-powered personal finance manager
[Source code](https://github.com/Santoshnani26/fintrack-serverless) · [Live demo](https://fintrackpro-demo.vercel.app)

A full-stack finance app with an agentic AI layer. Users track income, expenses and budgets on responsive dashboards. Five AI agents analyze spending by category, forecast monthly spend, suggest the top three savings, raise budget alerts and explain each result in plain English.

- **Stack:** Next.js, TypeScript, Express.js, MongoDB Atlas, FastAPI, LangChain
- **Backend:** JWT-based authentication and secure REST APIs

### Prajna: event-driven faculty performance management system
I contributed to the backend of a system that evaluates faculty performance. I worked on the Score Engine and Leaderboard modules and on REST APIs built with AWS Lambda. Backend services communicate through AWS EventBridge events and store data in DynamoDB.

- **Stack:** Node.js, TypeScript, React.js, AWS Lambda, EventBridge, DynamoDB, AWS CDK

### AI-based loan document processing system
A multi-agent pipeline built with LangGraph and LangChain. It classifies, extracts, validates and verifies loan documents using a local LLM served through Ollama. A Risk and Anomaly Detection agent finds inconsistencies across documents. A Decision and Report Generation agent combines the agent outputs into a structured, evidence-based assessment report for human review.

- **Stack:** Python, LangGraph, LangChain, Ollama
